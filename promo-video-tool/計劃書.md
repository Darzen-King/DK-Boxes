# AI 照片 → 宣傳影片工具｜計劃書

> BINI Blooms 商品社群宣傳影片產生器
> 用途：在 FB Reels / TikTok 發布商品宣傳影片，帶動網路銷售
> 性質：**店家自用的獨立本地工具**，暫不整合進現有會員系統

---

## 一、定位與策略

| 項目 | 結論 |
|---|---|
| 性質 | 獨立本地工具，不整合進現有 Firebase App |
| 操作者 | 店家/店員，後台手動，低流量 |
| 成品 | FB Reels / TikTok 用的**直式 9:16 MP4** |
| 語音 | **英文 + 他加祿語 Tagalog 雙版本** |
| 核心原則 | 簡單、低成本、少維護 |

> 社群觀眾多半**靜音滑過**，所以兩件事是「必須」不是「加分」：
> **(1) 燒錄字幕、(2) 畫面要動（Ken Burns 緩慢縮放）**。
> 純靜態圖配語音 = 廉價感，社群成效會很差。

## 二、為什麼是本地工具（最重要的架構決策）

因為是店家自用、低流量、產出社群影片 —— **ffmpeg 在自己電腦上跑就好**，
完全不用碰 Cloud Functions 的影片合成限制（記憶體/逾時/容器打包）。
這把整個專案最大的工程風險與雲端編碼成本直接歸零。

## 三、Pipeline

```
照片 + 商品資訊（手動填：名稱/價格/賣點）
   ↓
Claude Vision（看圖 → 寫英文 + 他加祿語行銷腳本，含前3秒 hook + CTA，分句輸出）
   ↓   ←── 文案可手動修改（行銷文案務必能改）
TTS（英文 + fil-PH 他加祿語 → mp3 + 時間軸）
   ↓
本機 ffmpeg（直式9:16｜Ken Burns縮放｜照片交叉淡入｜燒錄字幕｜背景音樂壓低｜品牌logo浮水印）
   ↓
social-ready MP4 ×2 語言 → 上傳 FB / TikTok
```

**工具型態**：跑在 `localhost` 的單頁小網站（Node + Express）—— 上傳照片→填資訊→生成→預覽下載。
**技術棧**：Node（沿用現有 Node 22 + npm 生態，學習成本最低）。

## 四、成本（每支影片）

| 項目 | 成本 | 說明 |
|---|---|---|
| Claude Vision 寫文案 | ~$0.005–0.02 | Sonnet，行銷文案品質值得 |
| TTS（英 + 菲，各一份） | ~$0.012（免費額度內近乎 $0） | Google fil-PH / en-* WaveNet |
| ffmpeg | 免費 | 在自己電腦跑 |
| 背景音樂 | 一次性 | YouTube Audio Library 免費可商用 |
| **合計** | **< $0.04 / 雙語一組** | 以店家用量，一個月幾美元，幾乎可忽略 |

## 五、分階段執行

- **Phase 0 — 前置（半天）**：申請 Anthropic + Google Cloud TTS 金鑰；裝 ffmpeg、Node；備好 logo、免費背景音樂、字型。
- **Phase 1 — 文案（進行中）**：照片 + 商品資訊 → Claude → **英文 + 他加祿語**腳本，先只輸出文字，驗證品質與可編輯性。
- **Phase 2 — 語音（半天）**：腳本 → TTS（英 + 菲）→ 試聽。**風險閘門**：發音不夠自然就改用 ElevenLabs。
- **Phase 3 — 影片合成（2–3 天，核心）**：本機 ffmpeg 直式、Ken Burns、字幕、音樂、浮水印 → 輸出 MP4。
- **Phase 4 — 包成 localhost 小工具（1–2 天）**：一鍵流程 UI。
- **Phase 5（未來選配）**：多模板／串 FB·TikTok 上傳 API／若要開放客戶自助才搬上雲端 + 防濫用。

## 六、關鍵風險與提醒

1. **他加祿語 TTS 品質**：Phase 2 一定要先試聽再往下做。
2. **社群演算法吃前 3 秒**：文案 prompt 明確要求「強 hook 開頭 + 結尾 CTA」。
3. **字幕時間軸**：用 TTS 回傳時間點或按句長粗分即可，先別上 Whisper（過度工程）。
4. **版權與標示**：背景音樂用免費商用庫；部分平台對 AI 生成內容有標示規定。

## 七、風格學習（讓 AI 模仿參考影片的口吻）

需求：餵約 20 支影片，讓 AI 學「說話方式與習慣用語」，再生成新影片。
這要拆成三層，可行性不同：

| 層面 | 做法 | 階段 |
|---|---|---|
| **文案用詞口吻** | 影片逐字稿 → Claude 濃縮成「風格檔」`style-profile.json` → 每次生成自動套用。**免訓練、in-context learning** | Phase 1 ✅ 已實作 |
| **旁白聲音像某人** | 抽乾淨人聲 → ElevenLabs voice cloning。**前提：須為本人聲音或有授權** | Phase 2 |
| **剪輯畫面風格** | 歸納規律（直式/節奏/字幕/轉場）→ 做成 ffmpeg 模板（複製模板，非「學習」） | Phase 3 |

> ⚠️ 素材若只有連結，需先用 `yt-dlp` 下載到本機才能處理。
> ⚠️ 版權：自己的影片最安全；他人影片學「用詞」風險低，但**重製畫面或克隆人聲**有法律與平台風險。
> ❌ Sora/Runway/Veo 這類生成式影片不適合——無法忠實呈現你真正的商品照片。

## 八、Plan B（不想裝環境/跑指令時）

無程式碼路線：Creatomate / Shotstack / json2video 模板 API + Make/n8n。
零維護，但每支付 render 費（~$0.1–0.5/支）、彈性較低。以店家用量，本地工具長期更省更可控。

## Phase 1 使用方式

```bash
cd promo-video-tool
npm install
cp .env.example .env      # 填入 ANTHROPIC_API_KEY

# （選用）先學風格：把參考影片逐字稿放進 transcripts/，產生風格檔
#   取得逐字稿（在自己電腦跑）：
#   yt-dlp --write-auto-sub --sub-lang "tl,en" --skip-download <影片連結>
node src/buildStyleProfile.js            # → 產生 style-profile.json

# 生成腳本（若有 style-profile.json 會自動套用該口吻）
node src/generateScript.js ./photos/rose.jpg --name "永生玫瑰禮盒" --price "NT$1280" --notes "情人節熱賣、可保存3年"
```

輸出：終端機顯示英文 + 他加祿語腳本，並存成 `output/<時間戳>.json`（供 Phase 2 TTS 使用）。

## Phase 2 使用方式（旁白語音合成）

預設用免費的 **edge-tts**；填入 `ELEVENLABS_API_KEY` 後自動切換到 ElevenLabs。

```bash
# 一次性：裝 edge-tts（要 Python）
pip install -U edge-tts

# 自動取 output/ 最新一份腳本 JSON，合成英文 + 他加祿語旁白
node src/synthesize.js

# 指定特定腳本、或強制 provider、或只做單一語言
node src/synthesize.js output/2026-05-30T....json
node src/synthesize.js --provider elevenlabs
node src/synthesize.js --lang tl --voice-tl fil-PH-AngeloNeural   # 男聲

# 看 edge-tts 有哪些 fil-PH 配音
edge-tts --list-voices | findstr fil-PH        # PowerShell
```

輸出：同資料夾產生 `<同名>-en.mp3`、`<同名>-tl.mp3`，以及 `<同名>-audio.json` 索引檔（供 Phase 3 影片合成使用）。

## Phase 3 使用方式（影片合成）

```powershell
# 一次性：確認 ffmpeg 裝好
ffmpeg -version

# （選用）放素材：
#   - 把品牌 logo 存成 LOGO.png（透明背景 PNG）放在專案根目錄
#   - 把背景音樂存成 music/bgm.mp3（沒有也可以，純旁白）

# 合成（自動取 output/ 最新一份腳本 + 音檔）
node src/composeVideo.js

# 只做他加祿語版
node src/composeVideo.js --lang tl

# 自訂素材
node src/composeVideo.js --music music/happy.mp3 --logo logos/bini.png
node src/composeVideo.js --photos photos/a.jpg photos/b.jpg photos/c.jpg
```

輸出：同資料夾產生 `<同名>-en.mp4` 和 `<同名>-tl.mp4`，1080×1920、30fps、H.264 + AAC，
可直接上傳 FB Reels / TikTok。

## 一鍵流程（含審稿閘門）

把三個 Phase 串成一條指令，**Phase 1 結束會暫停讓你檢查/修改腳本**再繼續做語音與影片：

```powershell
# 基本：把參數傳給 produce.js，Phase 1 結束會跳審稿提示
node src/produce.js .\photos\rose.jpg --name "永生玫瑰禮盒" --price "NT$1280" --notes "情人節熱賣"

# 加開網路搜尋：Claude 會先 google 趨勢/熱門 hashtag/季節梗（多花 ~$0.01–0.03）
node src/produce.js .\photos\rose.jpg --name "..." --notes "..." --web

# 只做他加祿語版影片
node src/produce.js .\photos\rose.jpg --name "..." --lang tl
```

**審稿閘門選項**：
- `[Enter]` 接受、繼續做旁白 + 影片
- `[e]`     用記事本開腳本 JSON 修改，存檔後再按 Enter 繼續
- `[q]`     停在這裡（之後可手動 `node src/synthesize.js` + `node src/composeVideo.js`）
