🇹🇼 中文操作步驟

  1. 雙擊桌面上的「🌸 BINI Blooms 製作工具」圖示
  2. 等黑色視窗跳出後自動縮到工具列，瀏覽器會自動開啟頁面（約 5 秒）
  3. 把商品照片拖進去虛線框內（也可以點選擇）
  4. 填寫商品名稱、價格、賣點（賣點越具體越好，例如「保存3年、附手寫卡片」）
  5. 選語言版本（雙語、純英文、純他加祿語）
  6. 按「🚀 開始製作」
  7. 等 AI 寫完腳本後，確認文字。不滿意可以直接點字修改
  8. 按「✅ 接受、繼續做旁白 + 影片」
  9. 等候製作完成（約 1–2 分鐘）
  10. 下方出現下載連結，點擊下載 MP4 到電腦
  11. 把 MP4 上傳到 FB Reels 或 TikTok

⚠️ 注意事項

  • 製作期間不要關任何視窗（黑色終端機視窗、或瀏覽器分頁）
  • 全部做完，關掉黑色視窗就會停止服務
  • 下次要再用，再次雙擊桌面圖示即可（不用重裝任何東西）
  • 如果第一次跑很慢（黑色視窗停在「安裝必要套件中…」）這是正常的，耐心等 1–2 分鐘
  • 想讓黑色視窗自動縮小到工具列？　右鍵桌面捷徑 → 內容 → 「執行」改成「最小化」→ 確定

🎞 可以上傳影片嗎？

可以。把 MP4/MOV/WebM 拖進虛線框就會自動處理：

  1. 系統用 ffmpeg 從影片等距擷取 6 張關鍵畫面給 AI
  2. AI 理解整支影片在介紹什麼（含動作、情境、時間順序）
  3. 生出符合影片內容的雙語腳本
  4. 那 6 張畫面也會作為 Phase 3 的素材，做成 9:16 直式短片

建議影片 ≤ 60 秒、檔案 ≤ 500 MB，畫質越清楚 AI 看得越準。

🔧 常見問題

  • 瀏覽器沒自動開？　手動開瀏覽器，網址列輸入 http://localhost:3000
  • 畫面卡很久？　從工具列把黑色視窗叫出來看，多半是網路問題或 API 額度用完
  • 找不到桌面圖示？　請店長按使用手冊重新做捷徑
  • 說「找不到 Node.js」？　請店長到 nodejs.org 安裝 LTS 版本

🇺🇸 English Guide

  1. Double-click the 🌸 BINI Blooms Tool icon on the desktop
  2. A black window appears briefly, then minimizes to the taskbar; the browser opens automatically (~5 seconds)
  3. Drag product photos into the dashed box (or click to choose)
  4. Fill in product name, price, and selling points (the more specific, the better — e.g. "lasts 3 years, includes handwritten card")
  5. Choose output language (both, English only, or Tagalog only)
  6. Click 🚀 Start
  7. Once the AI script appears, review the text. Click any line to edit inline
  8. Click ✅ Accept & continue to voiceover + video
  9. Wait 1–2 minutes for processing
  10. Download links will appear; click to save MP4 files
  11. Upload the MP4 to FB Reels or TikTok

⚠️ Important

  • Do not close any window during processing (the black terminal window or the browser tab)
  • When everything is done, close the black window to stop the service
  • To use it again later, just double-click the desktop icon (nothing else needs reinstalling)
  • If the first launch is slow (stuck at "Installing packages…"), that's normal — wait 1–2 minutes
  • Want the black window minimized automatically?　Right-click the desktop shortcut → Properties → set "Run" to "Minimized" → OK

🎞 Can I upload a video?

Yes. Drop an MP4/MOV/WebM into the dashed box and it'll be processed automatically:

  1. ffmpeg extracts 6 evenly-spaced key frames
  2. The AI understands the video's content (action, scene, sequence)
  3. It writes a bilingual script that fits the video's story
  4. Those 6 frames also become the visuals for the Phase 3 9:16 promo

Recommended: video ≤ 60s, file ≤ 500 MB. Clearer footage = sharper analysis.

🔧 Troubleshooting

  • Browser didn't open?　Open browser manually and visit http://localhost:3000
  • Stuck for a long time?　Restore the black window from the taskbar and check for errors — usually a network issue or out of API credit
  • No desktop icon?　Ask the manager to recreate the shortcut
  • "Node.js not found"?　Manager should install Node.js LTS from nodejs.org
